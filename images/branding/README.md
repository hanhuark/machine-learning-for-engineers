# Branding assets

`machine-learning-for-engineers-social-preview.png` is the repository social-preview candidate for the Machine Learning for Engineers public launch. It is a native composition of a two-tier cold-plate photograph and a BubbleID detection-and-segmentation result from Han Hu's cleared experimental-figure collection. It does not alter or extend the scientific content of either source figure.

The two cleared source figures and the reproducible Windows composition script are stored in this folder. The source imagery is for this repository's communications asset; it is not a packaged instructional dataset or a substitute for the corresponding study's provenance, context, or citation.

Set it through **Repository Settings → General → Social preview** after confirming that the crop and rendering meet GitHub's current preview requirements.
