# Access and license notes

## Access classes

| Class | Meaning | What may be added to this repository |
| --- | --- | --- |
| Open | A public landing page or full text was identified. | Stable link, citation, short original summary, and rights-compatible original teaching material. |
| Library | University-authenticated access may be required. | Citation, DOI/stable link, and a short original teaching note. Do not commit the source PDF unless its license permits redistribution. |
| Local copy | A copy is available in the course-reference collection. | Metadata and original synthesis only; confirm rights before copying figures, tables, or text. |
| Contributor-controlled | A future studio depends on a collaborator, dataset owner, or sponsor. | A public case description only after rights, technical accuracy, and scope are confirmed. |

## Rights rule for teaching material

The repository should primarily publish original explanations, original diagrams, short code, public data cards, and links. A downloaded paper or e-book is not automatically a redistributable course asset. For every figure, dataset, image, code fragment, or extended excerpt, record its source and reuse permission before publication.

## Version-sensitive resources

Agent harnesses, model products, APIs, MCP servers, and vendor skills change rapidly. Teach their durable engineering concepts—task specification, tool schemas, least privilege, logging, provenance, verification, and rollback—while placing product-specific instructions in dated, versioned pages.
