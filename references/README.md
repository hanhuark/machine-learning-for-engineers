# Reference library and reading paths

This directory makes the evidence base behind *Machine Learning for Engineers* inspectable. It is a curated guide, not a claim that every listed work has been reproduced, independently validated, or used as a classroom reading.

## Use the library

- Start with [`annotated_reference_map.csv`](annotated_reference_map.csv) to filter sources by module, engineering theme, and intended use.
- Use [`access_and_license_notes.md`](access_and_license_notes.md) before downloading, redistributing, or assigning a resource.
- Follow a reading path when preparing a module, studio, assessment, or book chapter.

## Evidence boundaries

An external source can support a concept, implementation example, or policy decision; it does not automatically validate a local teaching activity. Before a source becomes required course material, the instructor should check the current version, access conditions, license, technical fit, and any data/privacy implications.

## Citation and contribution expectations

Add a source only when its bibliographic details, stable URL or DOI, access route, and intended teaching use can be checked. Do not upload publisher PDFs, restricted library content, student work, or non-redistributable datasets to this repository.

## Reading paths

- [`beginner.md`](reading_paths/beginner.md): build intuition for modeling and evaluation.
- [`instructor.md`](reading_paths/instructor.md): design a defensible engineering learning experience.
- [`ai_literacy.md`](reading_paths/ai_literacy.md): connect AI use to engineering responsibility and assessment.
- [`physical_ai.md`](reading_paths/physical_ai.md): develop sensing, control, simulation, and hardware-connected activities.
- [`book_authors.md`](reading_paths/book_authors.md): turn evidence into a durable, citable chapter.
