# Reading path: beginner engineering learner

1. [First 30 minutes](../../learning_paths/00_first_30_minutes/).
2. Simeone: ML vocabulary and the basic supervised/unsupervised distinction.
3. Naser: coding and evaluation pathway for engineers new to programming.
4. One current module: regression, classification, or clustering.
5. [Engineering evidence checklist](../../docs/engineering-evidence-checklist.md) before interpreting a result.

The target is not algorithm recall. By the end, a learner should be able to name the engineering target, units, baseline, split, metric, and one likely failure mode.
