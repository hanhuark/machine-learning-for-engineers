# Reading path: book and chapter authors

1. Select one learner outcome and engineering question.
2. Use the annotated map to select one methodological anchor, one engineering case anchor, and one pedagogy/assessment anchor.
3. Apply the [chapter contract](../../book_companion/CHAPTER_CONTRACT.md).
4. Add a public reproducibility route, limitation statement, and instructor-use note.
5. Record source access and reuse constraints before reusing any non-original asset.

The book should remain downstream of tested, maintained repository material. A chapter is not complete merely because its prose is complete.
