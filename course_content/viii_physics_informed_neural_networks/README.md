# VIII. Physics-Informed Neural Networks

Physics-informed neural networks (PINNs) combine neural-network approximation with governing equations. In this module, a neural network approximates the transient temperature field in a one-dimensional rod while the heat equation, boundary conditions, and initial condition constrain its training.

The purpose is not to present PINNs as replacements for analytical or numerical heat-transfer methods. The analytical solution and a finite-difference solution are established first and are used to verify the PINN. Students then use sparse synthetic temperature observations to estimate an unknown thermal diffusivity and investigate conditions under which a PINN can give an inaccurate solution despite a decreasing training loss.

## Learning objectives

After completing this module, students should be able to:

1. Formulate a forward and inverse heat-conduction problem with explicit units, assumptions, initial conditions, and boundary conditions.
2. Explain collocation, initial-condition, boundary-condition, and observation points.
3. Use automatic differentiation to construct first- and second-order derivatives.
4. Construct the composite loss of a PINN and interpret each loss component.
5. Verify a PINN against analytical and finite-difference baselines on an independent grid.
6. Estimate thermal diffusivity from sparse, noisy temperature observations.
7. Diagnose loss imbalance, inadequate sampling, scaling problems, and model-form error.
8. Critically test AI-generated code or recommendations rather than accepting a successful run as evidence of physical validity.

## Engineering problem

The baseline system is a homogeneous, one-dimensional rod of length `L` with constant thermal diffusivity `alpha`. There is no internal heat generation, convection, radiation, or contact resistance. The temperature variable is the excess temperature above the fixed boundary temperature:

```math
\frac{\partial T}{\partial t}=\alpha\frac{\partial^2T}{\partial x^2},
\qquad 0<x<L,\quad t>0,
```

with

```math
T(0,t)=T(L,t)=0,
```

and

```math
T(x,0)=T_0\sin\left(\frac{\pi x}{L}\right).
```

The analytical solution is

```math
T(x,t)=T_0\exp\left(-\frac{\pi^2\alpha t}{L^2}\right)
\sin\left(\frac{\pi x}{L}\right).
```

The baseline parameters are:

| Quantity | Symbol | Value | Unit |
| --- | --- | ---: | --- |
| Rod length | `L` | 0.10 | m |
| Initial amplitude | `T0` | 50.0 | K above the boundary temperature |
| Thermal diffusivity | `alpha` | 1.0e-5 | m^2/s |
| Final time | `t_max` | 200.0 | s |

Because the dependent variable is an excess temperature, `T = 0 K` in the equations means zero temperature difference from the boundary, not absolute zero.

## PINN formulation

The network receives `(x, t)` and returns `T_theta(x, t)`. Automatic differentiation supplies `T_t` and `T_xx`. The physics residual is

```math
r_\theta=\frac{\partial T_\theta}{\partial t}
-\alpha\frac{\partial^2T_\theta}{\partial x^2}.
```

Training minimizes

```math
\mathcal{L}=w_f\mathcal{L}_{PDE}
+w_{IC}\mathcal{L}_{IC}
+w_{BC}\mathcal{L}_{BC}
+w_d\mathcal{L}_{data},
```

where the observation term is used only in the inverse problem. A low value of this composite objective is a convergence diagnostic, not independent validation.

## Data used in this module

- `data/reference_temperature_field.csv`: a dense analytical field used only for verification.
- `data/inverse_temperature_clean.csv`: 80 sparse, noise-free synthetic observations.
- `data/inverse_temperature_noise_0p50K.csv`: the same measurement design with reproducible Gaussian noise (`sigma = 0.50 K`).
- `data/inverse_temperature_noise_1p00K.csv`: a higher-noise sensitivity case (`sigma = 1.00 K`).
- `data/dataset_metadata.json`: parameters, units, evidence class, seed, and generation method.

All values are synthetic and generated by `scripts/generate_heat_equation_datasets.py`. They are not experimental measurements. Regenerate them with:

```powershell
python scripts/generate_heat_equation_datasets.py
```

## Interpretation limits

This module is a controlled teaching demonstration. It does not establish that PINNs outperform classical solvers, generalize to arbitrary initial conditions, or are validated for real material-property measurements. The inverse observations are generated from the same governing equation used by the PINN; real experiments introduce model-form error, uncertain boundary conditions, sensor dynamics, and correlated measurement errors.
