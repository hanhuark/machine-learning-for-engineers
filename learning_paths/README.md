# Learning paths

These paths make the curriculum easier to enter without reducing its engineering standard. They are designed for self-directed learners, students, and instructors who need to select an appropriate starting point.

## Choose a path

| Your starting point | Begin here | Expected outcome |
| --- | --- | --- |
| New to Python or machine learning | [First 30 minutes](00_first_30_minutes/) | Run, inspect, and explain a small engineering prediction workflow. |
| Comfortable with Python but new to engineering ML | [Foundations checklist](#foundations-checklist) | Select a core module with the needed conceptual preparation. |
| Ready to learn a method | [Core-module sequence](../COURSE_MAP.md) | Complete a module tutorial and its self-check before an assignment. |
| Bringing an engineering problem or data set | [Case-study framework](../case_studies/) | Frame the task, data rights, baseline, split rule, and validation need. |
| Teaching or adapting material | [Adoption guide](../ADOPTION_GUIDE.md) | Adopt a bounded module without treating a tutorial as a turnkey assessment. |

## Foundations checklist

Before beginning a core module, a learner should be able to:

1. read a CSV-like table and identify each variable, unit, and target;
2. make a plot with labeled axes and explain its physical meaning;
3. distinguish training data from a held-out test set;
4. compare a simple baseline with a more flexible model;
5. recognize that a low training error does not establish useful prediction; and
6. state one condition where a model should not be trusted.

If any item is unfamiliar, begin with the [First 30 minutes](00_first_30_minutes/) exercise and the repository's [Python/VS Code prerequisites](../prerequisites/). A web browser with Google Colab is sufficient for the first exercise; local Python is optional.

## A note for independent learners

The public tutorials are learning resources, not evidence that an individual has mastered a topic. Use the self-check prompts, reproduce the result, alter one assumption, and explain what changed. In a formal course, instructors should add protected individual checks or an individual defense as described in the [assessment policy](../teaching_resources/ASSESSMENT_AND_AI_POLICY.md).
